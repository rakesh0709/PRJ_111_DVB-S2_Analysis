# 04_AI_MODELS — Machine Learning Models & Weights

## Purpose
This directory is designated to store trained machine learning models, neural network architectures, pre-trained weights, and configuration files for anomaly detection and pattern recognition in DVB-S2 receiver output streams.

## Current Status
* **Status:** Planned / Future Implementation
* AI/ML model training and evaluation are scheduled for Phase 3. No trained weights or dummy model files exist at this stage.

## Intended Contents
* **Anomaly Detection Models:** Unsupervised and semi-supervised models (e.g., Isolation Forest, Autoencoders, LSTM/Bi-LSTM networks) for detecting corrupted frames, unexpected jitter, stream desynchronization, and transmission flaws.
* **Pattern Detection & Classification:** Models for classifying modulation types, RFI interference profiles, or recurring multiplex traffic patterns.
* **Model Metadata:** Serialized model weights (`.pt`, `.onnx`, `.pkl`), hyperparameter configurations, and evaluation metadata.
